# Truth or Dare Game

A fun, interactive **Truth or Dare** game built with **SvelteKit**. Whether you're with friends or just looking to spice up your night, this game offers an exciting mix of challenges, questions, and random fun!

**Note:** This repository will be archived. While the project will no longer be actively maintained or updated, feel free to explore, use, or fork it for your own purposes.

## Features

- **Truth and Dare Questions:** Get random questions to play the game.
- **R-Rated Questions:** A special set of adult-themed questions for a more daring experience.
- **Bottle Flip:** Add some extra randomness with a bottle-flipping mechanic that helps decide the player’s fate.
- **Custom Questions:** You can recommend new questions to expand the game’s collection.
- **Responsive Design:** Enjoy the game on mobile, tablet, or desktop.

## Installation

To get started with the game locally, clone the repository and run the following commands:

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/truth-or-dare.git
   ```

2. Install dependencies:

   ```bash
   cd truth-or-dare
   npm install
   ```

3. Run the development server:

   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000` to start playing!

## Features in Detail

### 1. **Truth or Dare Questions**
   - A random selection of truth or dare questions will be generated for players.
   - Choose between truth or dare, and let the game decide the rest!

### 2. **R-Rated Questions**
   - For adult players, there is a collection of R-rated questions to spice up the experience.
   - Toggle these questions on/off based on your preference.

### 3. **Bottle Flip**
   - A bottle-flipping game mechanic is included to determine who takes the next turn or what challenge they face.
   - Spin the bottle to make the game even more fun and unpredictable.

### 4. **Recommending New Questions**
   - Players can recommend new truth or dare questions to add to the game.
   - This keeps the game fresh with new content!
